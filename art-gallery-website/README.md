# ArtSpace — Art Gallery Website

A responsive student-level art gallery website made with HTML, CSS, and vanilla JavaScript.

## Pages included (9 total)
1. Home page
2. Gallery listing page
3. Login page
4. Sign-up page
5. The Starry Night
6. Mona Lisa
7. Girl with a Pearl Earring
8. The Great Wave off Kanagawa
9. The Scream

## Features
- Responsive gallery layout
- Artwork image, title, artist, year, medium, and description
- Three related artworks on each artwork detail page
- Gallery search by title, artist, or medium
- Login and sign-up form UI (demo only; no real account/database integration)
- Simple HTML/CSS/JavaScript; no build tools required

## Run locally
Extract the ZIP and open `index.html` in a browser. An internet connection is needed for the remote artwork images and Google Fonts.

## Publish with GitHub Pages
1. Create a GitHub repository and upload the contents of this folder.
2. In the repository, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait for the published URL to appear in the Pages settings.

The login and sign-up forms are front-end demonstrations only. They do not create accounts or store passwords.
